# Agentic AI Stack Repair Platform for Exoskeletons

This project provides a simple demonstration of an agentic AI-based system designed to diagnose and recommend repairs for robotic exoskeletons.  

The platform contains:

- **Diagnostics** module for interpreting sensor data and identifying potential faults.
- **RepairAgent** that produces step-by-step repair instructions based on diagnostics.
- **Command-line interface** to run an example analysis.

The repository also includes unit tests for core components.

## Usage

```bash
python main.py
```

## Running Tests

```bash
pytest
```
